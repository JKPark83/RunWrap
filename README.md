# 러너 리포트 (가칭)

애플워치 러닝 데이터를 의미 있는 지표로 재가공해 알려주고, 탭 한 번으로
인스타그램 스토리용 카드 이미지를 만들어주는 아이폰 전용 앱.
서버 없이 전부 온디바이스로 동작한다. 상세는 [기획서](docs/plan/기획서-v0.1.md) 참조.

## 구조

- `docs/plan/` — 기획서
- `ios/` — SwiftUI 앱 (xcodegen 프로젝트)

## 빌드

```bash
cd ios
xcodegen generate
open RunnerReport.xcodeproj
```

- iOS 17+, HealthKit 읽기 전용 (건강 데이터는 기기 밖으로 나가지 않는다)
- 시뮬레이터에는 워치 러닝 기록이 없으므로 실기기에서 확인한다

## 진행 상태 (MVP 로드맵, 기획서 §8)

- [x] 1단계 — HealthKit 연결: 권한 요청 → 최근 러닝 목록
- [ ] 2단계 — 리포트 엔진 (파생 지표 2~3개)
- [ ] 3단계 — 공유 카드 생성 (퀄리티 게이트)
- [ ] 4단계 — 인스타그램 스토리 연동
- [ ] 5단계 — 백그라운드 감지 + 알림
