## 1. M12-1 — 데이터 파이프라인

저장소 루트 `tools/course-poi/`에 재현 가능한 스크립트로 구성한다.
산출물은 `ios/RunWrap/CoursePOI.json` 하나 — sources가 폴더 단위라 xcodegen이 자동으로 리소스에 포함한다.

```
tools/course-poi/
├── fetch_osm.sh            # Overpass — 전국 drinking_water + toilets (키 불필요)
├── fetch_seoul_water.sh    # 서울 공원음수대 CSV (키 불필요)
├── fetch_stores.sh         # 상가업소정보 CSV → 편의점 추출 (로그인 필요 시 수동 다운로드로 대체)
├── geocode_toilets.sh      # 화장실 표준데이터 주소 → 좌표 (환경변수 KAKAO_REST_KEY, 커밋 금지)
└── build_poi.py            # 통합·중복 제거·경량 JSON 생성 + 건수 리포트
```

- **산출 포맷** (필드명 1글자로 용량 절약, 좌표는 소수 5자리 ≈ 1.1m 정밀도):

  ```json
  {"generatedAt": "2026-08-12", "pois": [
    {"k": "c", "n": "GS25 성수점", "la": 37.54321, "lo": 127.04567}
  ]}
  ```

  `k`: `c` 편의점 / `t` 화장실 / `w` 음수대. 예상 규모 약 11만 건, JSON 수 MB —
  용량이 부담되면 압축 포맷으로 전환(오픈 이슈 #3).
- **중복 제거**: 같은 종류끼리 30m 이내이면 하나로 합친다 (공공데이터·OSM 중복 대비).
- **완료 기준**: 스크립트 재실행으로 같은 산출물 재현 + 종류별 건수 로그 확인.

## 2. M12-2 — GPX 파서 + 매칭 엔진 (순수 로직)

기존 3계층 규칙(엔진은 Foundation만 import, 결정론적)을 그대로 따른다.

- **GPXParser**: XMLParser로 `<trkpt lat lon>` 추출(`<rte>`/`<wpt>`만 있는 파일은 rtept 폴백).
  좌표는 CoreLocation 대신 자체 `GeoPoint(lat, lon)` — 엔진의 Foundation-only 규칙 유지.
- **CourseSupplyEngine**:
  1. 코스 폴리라인의 세그먼트별 누적 거리를 전처리(하버사인).
  2. 각 POI에서 최근접 세그먼트로 수선을 내려 **이탈 거리**와 **누적 km 지점**을 계산.
  3. 반경 150m(기획서 §11) 이내만 채택, km 순 정렬.
- **미노출 가드**: 트랙 포인트 2개 미만 또는 총거리 500m 미만이면 분석하지 않음.
  종류별 0건이면 해당 섹션 미노출 + 음수대는 서울 외 지역 데이터 공백을 안내 문구로 노출.
- **성능**: 전체 POI 약 11만 건 → 코스 bbox(+300m 버퍼)로 1차 필터 후 정밀 계산.
- **완료 기준**: Swift Testing 통과 — 고정 좌표로 수선 거리·누적 km 기대값을 검증하고
  산출 근거는 주석으로 남김, 가드 케이스 포함.

## 3. M12-3 — 스토어 + 화면 + 탭

- **CoursePOIStore**: `@MainActor final class` + `ObservableObject`. 번들 JSON을 백그라운드에서
  디코드해 로드, `enum State`(idle/loading/loaded/failed) 패턴 유지.
- **CourseScreen**: 4번째 탭 "코스" (아이콘 map 계열).
  - `fileImporter`로 GPX 업로드 (UTType 등록), 마지막 코스는 로컬 캐시해 재진입 시 유지.
  - 상단 지도: `Map` + `MapPolyline`(세션 상세와 같은 스타일) + 종류별 핀.
  - 하단 리스트: "3.2km 지점 · GS25 (코스에서 40m)" — `.rrCard()`·RR 토큰 재사용.
  - 하단에 데이터 기준일 + 출처 표기(공공데이터·OSM ODbL).
  - 시뮬레이터·데모용 **샘플 코스**(한강 코스 GPX) 내장 — DemoData 원칙과 동일.
- **RootView**: 탭 추가 후 `xcodegen generate` → 전체 테스트.
- **완료 기준**: 시뮬레이터에서 샘플 GPX 업로드 → 지도+리스트 표시, `xcodebuild test` 전체 통과.
