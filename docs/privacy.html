런미새 개인정보 처리방침

최종 수정일: 2026년 9월 29일 · 적용 버전: 1.3 이상

런미새는 사용자의 건강 데이터를 수집하지 않습니다. 애플 건강(Health) 앱에서 읽은 러닝·활력징후 데이터는 아이폰 안에서만 계산에 쓰이며, 어떤 서버로도 전송되지 않습니다.

계정도 없고, 로그인도 없고, 광고나 분석 SDK도 없습니다. 성장 진행도만 사용자 본인의 iCloud에 백업합니다. 개발자는 사용자가 어떤 기록을 가지고 있는지 알 방법이 없습니다.

1. 앱이 읽는 데이터

런미새는 애플 HealthKit에 읽기 전용 권한만 요청합니다. 건강 데이터에 쓰거나 지우지 않습니다. 읽는 항목은 아래가 전부이며, 처음 건강 앱과 연결할 때(온보딩) 한 번에 요청합니다. 체중은 요청하지 않습니다.

2. 데이터를 어디서 처리하나

모든 계산은 아이폰 기기 안에서 이루어집니다. 개발자가 운영하는 서버가 없고, 사용자 계정이 없으며, 건강 데이터를 담은 어떤 요청도 외부로 나가지 않습니다.

앱이 만드는 결과물(주간 리포트, 체력 배터리, 훈련 처방 등)도 기기에만 남습니다. 알림 본문에 쓸 최소한의 요약(문장 한 줄, 주간 거리, 러닝 횟수)을 앱 내부 저장 공간에 파일로 두는데, 이 파일은 iCloud·아이튠즈 백업에서 제외되도록 표시합니다.

예외로, 앱을 다시 설치했을 때 성장 진행도를 되살리기 위해 진행도 스냅샷 1건을 사용자 본인의 iCloud(CloudKit 개인 데이터베이스)에 저장합니다. 건강 데이터는 들어 있지 않습니다. 자세한 내용은 §3 (5)를 보세요.

대회 상세에서 '캘린더에 추가'를 누르면 그 대회 1건(이름·날짜·장소·홈페이지)을 기기 캘린더에 이벤트로 저장합니다. 캘린더 권한은 "쓰기 전용"만 요청하므로 앱은 기존 일정을 읽지 못하며, 버튼을 누를 때만 권한을 묻습니다. 즐겨찾기한 대회의 접수 알림(접수 시작일·마감 3일 전)은 기기 안에서 예약하는 로컬 알림으로, 서버를 거치지 않습니다.

3. 외부와 통신하는 경우

런미새가 인터넷에 접속하는 경우는 아래가 전부이며, 어느 것도 건강 데이터를 싣지 않습니다.

(1) 날씨 조회

  • 대상: Open-Meteo 공개 날씨 API
  • 보내는 값: 좌표(위도·경도)뿐입니다. 좌표는 소수점 둘째 자리로 뭉개서 보냅니다(약 1km 단위) — 정확한 위치가 아니라 "이 동네" 수준입니다.
  • 보내지 않는 값: 기기 식별자, 사용자 식별자, 건강 데이터, 러닝 기록.
  • 쓰는 곳: 지금 날씨와 오늘 최고기온을 받아 복장·수분 섭취를 안내하고, 같은 요청으로 24시간 시간대별 예보를 받아 달리기 좋은 시간을 추천합니다(보내는 값은 위와 같이 좌표뿐입니다). 위치 권한은 "앱 사용 중"만 요청하며, 거부하면 날씨 관련 카드만 표시되지 않습니다.
  • 참고: 지나간 러닝에 붙는 기온·습도는 네트워크로 받아오는 값이 아니라, 애플워치가 운동 기록에 함께 저장해 둔 값을 읽은 것입니다.

(2) 대기질 조회

  • 대상: 한국환경공단 에어코리아 공공데이터 API(apis.data.go.kr)
  • 보내는 값: 기기 안에 들어 있는 측정소 목록에서 기기가 직접 고른 가장 가까운 측정소 이름과 앱 인증키뿐입니다. 좌표는 보내지 않습니다.
  • 쓰는 곳: 미세먼지·초미세먼지 수치로 야외 러닝 여부와 복장을 안내합니다. 받은 수치는 기기에 1시간 동안 보관해 같은 요청을 줄입니다.

(3) 대회 일정 조회

  • 대상: 이 앱 저장소의 정적 파일(raw.githubusercontent.com — GitHub에 올려둔 대회 일정 JSON)
  • 보내는 값: 없습니다. 파일 하나를 내려받는 단순 조회입니다.
  • 쓰는 곳: 국내 마라톤 대회 목록 표시.

(4) 대회 이미지

  • 대상: 대회 목록 JSON에 적힌 외부 이미지 주소. 주최측 홈페이지와 그 이미지 서버(CDN)뿐 아니라 대회 소식을 실은 언론사·포털(네이버·카카오 등)의 이미지 서버일 수도 있습니다. 호스트는 대회마다 다릅니다.
  • 대회 카드와 상세 화면의 포스터·썸네일을 해당 주소에서 바로 불러옵니다.
  • 요청에는 일반적인 웹 요청 정보(IP 주소, 기기 종류 등)만 실리고, 개인정보·건강 데이터는 없습니다.

(5) iCloud 진행도 백업

  • 저장 위치: 사용자 Apple 계정의 CloudKit 개인 데이터베이스(컨테이너 iCloud.com.jkpark.runwrap). 개발자는 이 데이터를 열람할 수 없습니다.
  • 저장하는 값: 러닝 레벨·목적·주간 목표·온보딩 날짜, 성장 사이클 시작일·최고 단계, 목표 레이스(종목·목표 기록·날짜), 도감(새 종류·수집일·당시 목표 문구·걸린 일수), 직접 입력한 대회 기록(종목·기록·날짜).
  • 저장하지 않는 값: 건강 앱에서 읽은 운동 기록·심박·경로·위치 등 건강 데이터 일체.
  • iCloud에 로그인하지 않은 경우: 백업을 건너뛰고, 기기 안의 진행도는 그대로 유지됩니다. 이때는 앱을 다시 설치하면 진행도를 되살릴 수 없다고 안내하고 새로 시작합니다.
  • 삭제 방법: 설정 앱 → [사용자 이름] → iCloud → 저장 공간 관리(iOS 버전에 따라 "계정 저장 공간 관리") → 런미새 → 데이터 삭제. 앱이 설치된 채로 진행도가 바뀌면 다시 백업되므로, 완전히 지우려면 앱을 먼저 삭제한 뒤 진행하세요.

(6) Apple 지도

  • 코스·세션 지도, 대회 상세의 대회장 지도, 공유 카드를 그릴 때, 지도에 표시되는 영역의 지도 타일을 Apple 지도 서비스에 요청합니다.
  • 이 요청으로 대략적인 지역이 Apple에 전달될 수 있으며, 여기에는 Apple 개인정보 처리방침이 적용됩니다.

4. 제3자 제공·판매·광고

  • 건강 데이터를 누구에게도 제공하거나 판매하지 않습니다.
  • 광고, 마케팅, 데이터 마이닝, 사용자 프로파일링에 쓰지 않습니다.
  • 광고 식별자를 쓰지 않고, 사용자 추적을 하지 않습니다.
  • 분석·크래시 리포팅을 포함한 제3자 SDK를 하나도 사용하지 않습니다. 이 앱은 애플이 제공하는 프레임워크만으로 만들어졌습니다.
  • 법령에 따른 요구가 있어도 개발자가 넘길 수 있는 건강 데이터가 애초에 없습니다.

5. 보관 기간과 삭제

  • 건강 데이터의 원본은 애플 건강 앱이 보관하며, 런미새는 이를 계산할 때 읽기만 합니다.
  • 앱이 기기에 남기는 것은 설정값(러닝 목적·레벨·알림 시각 등), 성장 진행도·도감, 직접 입력한 대회 기록·최고 기록 기준, 불러온 GPX 코스, 그리고 알림용 요약·대기질·대회 목록 캐시 파일입니다.
  • 직접 등록한 러닝화 목록과 러닝별 배정(shoes.json)도 기기 안에만 저장되며, iCloud 진행도 백업에는 포함되지 않습니다.
  • 앱을 삭제하면 기기 안의 이 파일과 설정값은 함께 사라집니다. 다만 사용자 본인의 iCloud에 백업된 진행도 스냅샷(§3 (5))은 남습니다.
  • iCloud 진행도 스냅샷 삭제: 설정 앱 → [사용자 이름] → iCloud → 저장 공간 관리(iOS 버전에 따라 "계정 저장 공간 관리") → 런미새 → 데이터 삭제.
  • 읽기 권한은 언제든 되돌릴 수 있습니다: 설정 앱 → 개인정보 보호 및 보안 → 건강 → 런미새 또는 건강 앱 → 프로필 → 앱 및 서비스 → 런미새.

6. 아동의 개인정보

런미새는 아동을 대상으로 하지 않으며, 나이를 포함한 어떤 개인정보도 개발자 서버에 수집하지 않습니다. 생년월일은 최대 심박 추정에만 쓰이고 기기를 벗어나지 않습니다.

7. 의학적 조언이 아닙니다

런미새가 보여주는 해석·지표·훈련 처방은 러닝 기록을 바탕으로 한 참고 정보이며, 질병을 진단·치료·예방하기 위한 의료기기나 의학적 조언이 아닙니다. 통증이나 이상이 있다면 반드시 전문가와 상담하세요.

8. 방침 변경

이 방침이 바뀌면 이 페이지의 내용과 상단의 최종 수정일을 갱신합니다. 데이터를 다루는 방식이 실질적으로 바뀌는 경우에는 앱 업데이트 안내에도 함께 적습니다.
