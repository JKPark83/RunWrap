## 베타 앱 설명 (Beta App Description)

```
런미새는 애플워치로 기록한 러닝을 대신 읽고 해석해 주는 아이폰 앱입니다.

숫자를 나열하는 대신 "이번 주 훈련이 무리였는지", "몸이 나아지고 있는지"를 문장으로
알려드립니다. 주간 거리 증가율(10% 규칙), 부하 비율(ACWR), 심박 효율(EF) 같은 지표를
계산하되, 표본이 부족하면 그 지표를 아예 내지 않습니다 — 틀린 해석은 없느니만
못하다고 보기 때문입니다.

읽어 온 건강 데이터는 전부 아이폰 안에서만 처리하고 외부로 보내지 않습니다.
```

## 테스트할 항목 (What to Test)

```
[준비]
애플워치로 기록한 러닝이 건강 앱에 있으면 가장 좋습니다. 기록이 없어도
설정(리포트 탭 우측 상단 톱니) → 데모 모드 → "샘플 데이터로 둘러보기"를 켜면
합성 데이터로 모든 화면을 볼 수 있습니다.

[1. 홈 탭 — 오늘 뛸까 말까]
- 판단 카드 한 줄(예: "가볍게만 다녀오세요")이 오늘 몸 상태와 맞는 말인지
- 체력 배터리·날씨/복장·오늘 권장 거리가 실제 체감과 맞는지
  (날씨는 위치 권한 필요, 거절해도 앱은 동작)
- 마지막 러닝 카드를 탭하면 상세 화면이 제대로 열리는지

[2. 리포트 탭 — 이번 주 해석]
- 맨 위 한 줄 요약이 내 한 주와 맞는 말인지
- 주간 거리·부하 비율(ACWR)·심박 효율 카드의 숫자가 워치 기록과 어긋나지 않는지
- "자세히 보기"로 들어간 상세 화면의 설명이 이해되는지

[3. 리포트 탭 → 발전상 — 장기 추이]
- 월별·주별 추이 차트가 실제 훈련량 흐름과 맞는지
- 차트의 막대나 포인트를 탭했을 때 값이 제대로 뜨는지

[4. 코스 탭 — 현재 위치·GPX]
- 탭에 들어가면 현재 위치가 지도에 뜨고, 반경 1km 안의 보급 지점이 가까운 순으로
  나오는지 (위치 권한 필요, 거절하면 안내 문구가 대신 표시)
- 음수대·화장실·편의점 버튼으로 종류를 켜고 끌 수 있는지 (화면 버튼 이름 그대로)
- 목록에 뜬 음수대·화장실·편의점이 실제와 맞는지
- 내 GPX 파일을 올렸을 때 제대로 읽히고, 코스 기준 "몇 km 지점" 표기로 바뀌는지
- "현재 위치로 보기"를 누르면 올린 코스가 풀리고 다시 주변 보급 지점으로 돌아오는지

[5. 대회 탭]
- 다가오는 국내 대회 목록이 최신인지, 잘못된 정보가 있는지

[6. 러닝 스토리 카드 공유]
- 카드 이미지가 잘 만들어지고 사진 앱에 저장되는지

[알려 주셨으면 하는 것]
- 문장 톤이 과하거나 어색한 곳
- 숫자가 워치·건강 앱 값과 다른 곳 (가장 중요합니다)
- 있어야 할 카드가 안 보이거나, 반대로 표본이 없는데 뜬 카드
- 크래시·멈춤 (발생 직전에 무엇을 눌렀는지 함께 알려 주세요)
```

## 베타 앱 심사 정보 (외부 테스터용)

```
계정·로그인은 필요 없습니다.

애플워치 러닝 기록이 없는 기기에서는 설계상 화면이 비어 보입니다. 앱에 내장된
데모 모드로 전체 기능을 확인하실 수 있습니다:
설정(리포트 탭 우측 상단 톱니) → 데모 모드 → "샘플 데이터로 둘러보기" 켜기.
비어 있는 리포트 화면의 "샘플 리포트 둘러보기" 버튼으로도 바로 볼 수 있습니다.

건강 데이터는 읽기 전용으로만 접근하며 기기 밖으로 전송하지 않습니다.
자세한 내용은 App Review 심사 노트와 동일합니다.
```
